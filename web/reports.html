Laporan Penjualan

Langkah-langkah Generate Laporan
1
Proses Data (C Engine)
Export transaksi ke CSV lalu jalankan C Processor untuk menghitung subtotal, diskon, dan sorting.
2
Generate Laporan (COBOL Reporter)
Jalankan COBOL Reporter untuk membuat laporan rekapitulasi, penjualan harian, dan produk terlaris.
Laporan Pendapatan
Laporan belum digenerate. Ikuti langkah-langkah di atas: 1. Klik "Proses Data" untuk menjalankan C Engine 2. Klik "Generate Laporan" untuk menjalankan COBOL Reporter 3. Laporan akan tampil di sini
